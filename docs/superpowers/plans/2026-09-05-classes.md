# Classes Implementation Plan

**Goal:** Implement the approved teacher-code, invitation-class, and assignment dashboard flow.
**Architecture:** A dedicated Hono classroom router with MongoDB persistence and database
role/ownership checks; focused React class, assignment editor, runner, and report components.
**Tech Stack:** Existing Hono, MongoDB, React, Tailwind; Node tests and React Testing Library.
**Spec:** ../specs/2026-09-05-classes-design.md

## Global constraints

No frontend teacher secrets; teacher is distinct from admin. Only class owners see
classmate results. Server computes grades. Assignment question keys stay private before
submission. English/Chinese UI; phone/tablet/desktop responsive. Preserve unrelated scratch files.
